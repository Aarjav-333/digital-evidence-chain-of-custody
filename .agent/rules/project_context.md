# Workspace Rule: Project Context Synchronization

1. **Session Initialization**:
   - Read `PROJECT_CONTEXT.md` at the start of every session before analyzing or modifying any project code.
   - Familiarize yourself with the implemented features, architecture, database schema, and design system rules documented therein.

2. **Continuous Updates**:
   - After every feature, fix, or UI change, update the status table, the To-Do checkboxes, and the changelog in `PROJECT_CONTEXT.md` in the exact same commit.

3. **Integrity & Standards**:
   - Follow the shared design system tokens defined in `frontend/src/styles/theme.css`.
   - Never break cryptographic verification, chain of custody logging, or role-based access control.
   - Keep git workflow standards: commit with conventional prefixes and push to `origin main`.
